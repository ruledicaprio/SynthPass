- **Tier 1 now parses only the text of the OCR pass the retry loop accepted.** The retry loop
  appends every pass's candidate lines to the page text, and Tier 1 used to parse all of it. When
  two passes left disagreeing damaged-capture readings, `mrz`'s unanimity gate refused both and the
  loop's own accepted reading was lost. Tier 1 now reads that pass's text
  (`OcrPage::accepted_mrz_text`), and falls back to the full text only when no single pass was
  accepted. Tier 2 and the saved `.md` file still get every line. A Tier-1 outcome can change on a
  document the loop accepted on a retry pass (#508).
