- **Opt-in embedded VIZ fonts.** `synthpass generate` and `synthpass export` accept `--viz-font` with a fixed embedded font or `random`, selected deterministically from a separate seed stream. Per-field scales are computed once per layout and font to stay inside PT Sans's permitted ink area; random selection filters refused fonts. Labels and export records include the actual `viz_font` only when requested; default output and OCR-B MRZ rendering remain unchanged (ADR-0030 Decision 5, as amended in #708).
