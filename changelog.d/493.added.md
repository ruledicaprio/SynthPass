- **`--json` gives `synthpass`/`synthpass batch` a script-parseable output contract.**
  `synthpass <image> --json` prints exactly one line of compact JSON — the v2 `ExtractionV2`
  object — to stdout; `synthpass batch <dir|glob> --json` prints [JSON Lines](https://jsonlines.org/),
  one compact `ExtractionV2` object per successfully extracted document, in input order. A
  document that fails extraction writes no stdout line under `--json`, only a stderr error.
  Default (non-`--json`) output is unchanged, apart from moving every progress and diagnostic
  line (the config echo, "Processing local file...", "OCR successful!", batch's summary line) to
  stderr in *both* modes — stdout now carries only extraction content, never progress noise.
  See `knowledge/decisions/ADR-0023-cli-output-contract.md` (#493).
