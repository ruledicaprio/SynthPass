- **A new `synthpass-layout` crate reads layout files.** One JSON object states the format and the eleven rectangles of a layout (`knowledge/LAYOUTS.md` is the reference), the five built-in layouts are committed as such files and load through the same parser and checks, and a layout's identity is the SHA-256 of its validated geometry. Nothing a user sees changes: `synthpass generate` has no `--layout` flag yet, and generated pixels are unchanged.
