- **A license that lacks a feature no longer blocks it.** `synthpass batch`, `synthpass export`,
  `POST /api/extract/batch` and `GET /metrics` used to refuse (exit 3, or `403`) when the license
  did not list `batch`, `export` or `metrics`. They now run: the CLI prints one warning on stderr,
  and `synthpass-serve` logs one warning per feature and counts each accepted request in a new
  `synthpass_unentitled_requests_total{feature="batch"|"metrics"}` series on `/metrics`.
  `synthpass batch` still needs a valid license, as single-document extraction does;
  `synthpass export`, which is not extraction, no longer needs one; `GET /api/jobs/{id}` no longer
  checks the license. A script that relied on exit 3 or `403` for a missing feature will now see
  the command succeed (#494).
