- **Non-default `SYNTHPASS_OCR_*` knobs are now visible in extraction output.** The five
  `synthpass-ocr` measurement arms (`SYNTHPASS_OCR_TEXTURE`, `_ORDER`, `_ROTATE`, `_SKEW`,
  `_CHARGRID`) plus `SYNTHPASS_OCR_MAX_PASSES`/`_MAX_SECONDS` are
  recorded — env var name to effective value, only when it differs from the default — in
  `ExtractionV2`'s new `trace.config_overrides` field, and `synthpass`/`synthpass batch` print
  the same values once on stderr when at least one is non-default:
  `⚙️  [Rust] non-default OCR knobs: SYNTHPASS_OCR_MAX_PASSES=1 SYNTHPASS_OCR_TEXTURE=off`. A
  default run's output is unchanged, on stdout or on disk.
