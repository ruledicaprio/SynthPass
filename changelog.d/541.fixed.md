- **`synthpass-bench` and `provider-bench` honour `SYNTHPASS_OCR_MODEL_DIR`.** Both binaries used
  to load `text-detection.rten`/`text-recognition.rten` from the tree they were compiled in
  regardless of the variable, unlike the CLI, the pipeline, and `ground_truth.rs` — a binary
  copied elsewhere silently read whatever `.rten` files sat in its build tree. Both now resolve
  `SYNTHPASS_OCR_MODEL_DIR` when set, falling back to the build tree's repo root exactly as
  before when it is unset. Both print the resolved detection/recognition paths on stderr at
  startup and record them (canonicalized where possible) as a new run-level `model_paths` field
  in their JSON reports; an older report simply lacks the key (#541).
