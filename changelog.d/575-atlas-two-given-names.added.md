- **`glyph_atlas --two-given-names`** (off by default) gives each seed's identity a second given name, so line one's name field holds a single filler between two letters, a position the generator's own names never produce (it draws one given name). The second name is the given name of the identity drawn for the seed plus 2^32, through the same document type; nothing else of the seed's identity changes, and a default run writes what it always wrote. The flag adds `-two-given-names` to the default output directory name. This is a bench-only example; no product code changes.
