- **A `glyph_atlas` example measures what the OCR models do with the `P<` cells of a synthetic TD3 MRZ, one degradation at a time.** `cargo run -p synthpass-ocr --release --example glyph_atlas` renders TD3 pages with the vendored OFL OCR-B font and degrades each on its own axis: resolution, real JPEG quality, rotation, blur, noise and ink density. For cells 0 and 1 of line one it records the detection-map values and, from the raw CTC matrix of the true line crop, the probability of the true glyph, the winner, the runner-up and the margin, plus the beam decoder's read as a control. Output is a local per-seed `records.jsonl` and an aggregate-only `summary.json` (percentiles and Wilson intervals). It refuses unpinned models, refuses an in-tree `--out` that git does not ignore, and aborts if its copy of the `ocrs` alphabet disagrees with `ocrs`'s own greedy read. It is a measurement tool: nothing in the shipped pipeline changes, and results are labelled "Observed on synthetic renders, vendored font, oracle crop". The `probe_matrix` example now also reads the models from `SYNTHPASS_OCR_MODEL_DIR` when it is set, falling back to the repo root as before (#433).
