- **`synthpass generate`'s label sidecar moved to `<stem>.labels.json`.** It used to share
  `<stem>.json` with extraction's own output, so reading a generated pass back (as the README
  walkthrough does) silently overwrote the very labels the read was graded against. Directories
  generated before this change keep their old `<stem>.json` files; nothing reads them as ground
  truth any more, so regenerate or rename them by hand if you still need them (#514).
