- **`SYNTHPASS_MRZ_DATE_DIGITS` (`off`, `control` or `on`) applies `mrz::ParseOptions::date_digits` to Tier 1, and it is off by default and unmeasured (#579).** Read like `SYNTHPASS_MRZ_CLASS_SWEEP`: `on` requires the two date fields of the read to hold digits or fillers, `control` is a placebo identical to `off`, and an unrecognised value falls back to `off` silently, so quote the arm the report names. `synthpass_die::date_digits_arm()` resolves it and `mrz_parse_options()` applies it, so `read_tier1`, the synthetic benchmark's Tier-1 read and `provider-bench`'s dump zone all follow it. The arm is recorded in `trace.config_overrides` when not `off`, `--write-baseline` and `--assert-baseline` refuse a baseline measured with it on, both benchmark reports carry `mrz_date_digits_arm`, the OCR-dump run manifest's `mrz_arms` gains `date_digits`, and `tools/bench_ab_diff.py` names it in the identity block. `synthpass_die::mrz_parse_options_for` and `mrz_config_overrides_from` take the extra argument. With the arm `off` the reads are unchanged.
