- **`provider-bench`'s `by format:` line and the outcome ledger's `mrz_format` column no longer
  take a real specimen's format from a checksum-invalid read.** A specimen whose deterministic
  MRZ read failed its own ICAO checksums still handed that read's `mrz_format` to the report, so
  a redacted passport whose fallback read started with `V` counted toward MRV-B.
  `resolve_mrz_format` now takes the provider's own read only when it is checksum-valid, and
  otherwise falls back to the ground-truth guess, or `unresolved` when there is none. Each
  document's outcome and miss bucket, and the Tier-1 gate, are unchanged; only the format label
  moves (#555).
