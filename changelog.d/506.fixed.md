  A second noise filter drops lines holding an unbroken run of more than 64 characters (background
  microprint misread as text; no MRZ or field line in the fixture corpus runs past 48). If the
  prompt still doesn't fit, it is capped so that it plus the 500-token output budget fits
  `SYNTHPASS_MODEL_N_CTX`: MRZ-shaped lines are always kept, then other lines in document order;
  it errors only when the MRZ-shaped lines alone don't fit. The old check ignored the output
  budget. `PROMPT_VERSION` moves from 2 to 3 (#506).
