- **`position_class(format, line, column)` and `PositionClass`.** They say which characters a format's ordinary layout allows at one cell: `Digit` (a check digit), `DigitOrFiller` (a date cell, and TD3's personal-number check digit, which an issuer may print as `<` when the personal number is unused), `Letter` (the first document-code cell), `LetterOrFiller` (the second document-code cell, issuing state, nationality, sex and name) or `Any` (document number and optional data); `PositionClass::allows(char)` tests one character. The function reads no text, so a long document number's filler in place of its check digit is not modelled. The digit classes are exactly the cells in which `find_and_parse`'s repair turns a misread letter into a digit, and a test keeps the two in step. Additive: no existing function changes.
