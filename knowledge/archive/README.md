# archive/

Historical record, not living documentation. Everything here predates or was superseded by a
current document — `ROADMAP.md`, `VISION.md`, `ARCHITECTURE.md`, or an ADR — and is kept for
provenance: the reasoning that led to the current state, not a description of it.

**Rule:** when a document here disagrees with anything outside this directory, the document
outside wins. Nothing here is updated as the codebase changes; each file is a snapshot of what
was proposed or believed at the time it was written, banner-noted with what superseded it.
