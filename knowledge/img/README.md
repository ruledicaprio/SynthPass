# img/

Image assets embedded by other documents in this tree — regenerated benchmark charts and a
handful of hand-taken screenshots. Nothing here is authored directly; each file is either
produced by a script/workflow or a manual capture kept as reference. Do not hand-edit an SVG in
this folder — regenerate it from its source instead (see
[`../benchmarks/README.md`](../benchmarks/README.md#live-tracks)).

## What belongs here

- **Per-track bench trend charts** (`bench-chart`, `scripts/run-bench.ps1` /
  `.github/workflows/bench-charts.yml`) — one SVG per track, regenerated whenever that track's
  `results/<track>-bench/history.jsonl` gains a row. Never auto-committed; a human reviews the
  regenerated file before it lands on `main`.
- **The per-format comparison bar chart** (`bench-chart --bars`) — one SVG comparing several
  tracks' latest numbers side by side.
- **Screenshots** of the CLI/serve output and the web validator, kept as a visual reference for
  README prose. Not regenerated by any script; replace by hand if the UI changes enough to make
  one stale.
